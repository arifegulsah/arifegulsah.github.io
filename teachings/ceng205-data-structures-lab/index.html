CENG205 Data Structures (Lab)

Laboratory sessions of the undergraduate Data Structures course, covering memory management, algorithm analysis, stacks, queues, linked lists, trees and graphs with hands-on C programming.

Term: 2025–2026 Fall

Role: Lab Teaching Assistant

Slides and C code examples I prepared for the weekly lab sessions. Slides are in Turkish and English.
